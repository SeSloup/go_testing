# Тестирование сервера «Поиск кафе»
В предыдущем уроке вы должны были развернуть у себя на локальной машине проект с сервером, возвращающим список кафе. Кроме этого, практическим заданием урока было самостоятельно написать тестовую функцию, которая бы проверяла негативные сценарии в запросах. Таким образом, с учётом функции TestCafeWhenOk(), которая была приведена в начале урока, у вас в проекте должен быть файл main.go с кодом сервера и файл main_test.go с двумя тестовыми функциями.
Сервер имеет один обработчик для пути /cafe, которому можно передать три параметра:

    city — название города. Это обязательный параметр со значением moscow или tula. Например, /cafe?city=moscow;
    count — количество возвращаемых кафе в указанном городе. Если не указан или в городе меньше кафе, то будут возвращаться все кафе города. Например, /cafe?city=tula&count=3;
    search — строка поиска. Возвращаются кафе, которые содержат в имени переданную строку. Поиск идёт без учёта регистра. Например, /cafe?city=moscow&search=завтраки.

Сервер возвращает список кафе в виде строки, в которой они разделены запятыми. Например, Пир и мир, Красиво есть не запретишь, Поздний завтрак.
Для сервера уже имеется проверка корректных и некорректных запросов, но мы ещё не проверяли, правильно ли отрабатывает сервер, когда указан параметр count, и верно ли работает поиск по подстроке из параметра search. Это вам и нужно будет сделать в этом проекте.

В main_test.go две тестовые функции:

    TestCafeCount() — проверяет работу сервера при разных значениях параметра count;
    TestCafeSearch() — проверяет результат поиска кафе по указанной подстроке в параметре search.

Требования к каждой тестовой функции даны ниже. При реализации используйте функции пакетов assert и require. С помощью require.Equal() следует проверить, что запрос успешно обработан, а функции assert использовать для проверки корректности результатов.
Функция TestCafeCount()
Вам необходимо отправить запросы с различными значениями count и подсчитать количество возвращаемых записей. Помните, что кафе возвращаются одной строкой и разделены запятыми. Разбить строку на слайс можно функцией strings.Split(s string, sep string) []string, после этого достаточно сравнить длину слайса с ожидаемой. Можно указывать любой город в запросах. Вот какие варианты вам нужно проверить:

    count=0 — не возвращается ни одного кафе;
    count=1 — возвращается одно кафе;
    count=2 — возвращается два кафе;
    count=100 — возвращается минимум из общего количества кафе и 100.

Полное количество кафе в городе можно получить из len(cafeList[город]). Переменная cafeList хоть и не экспортируема, но доступна в тестах, так как тесты принадлежат этому же пакету.
В функции можно определить тестовую таблицу со структурами типа:

requests := []struct {
        count int   // передаваемое значение count
        want  int   // ожидаемое количество кафе в ответе
    }{
        ...
    } 

Функция TestCafeSearch()
Если в запросе есть параметр search, то сервер возвращает все кафе, в названии которых имеется указанная строка. Поиск идёт без учёта регистра. Вам нужно проверить, что полученные в ответе кафе точно содержат переданную в search строку. Для этого нужно получить из ответа слайс строк и проверить каждое название с помощью функции strings.Contains(s string, substr string) bool.  Не забывайте перед сравнением приводить оба параметра к одному регистру - strings.ToUpper(s string) string или strings.ToLower(s string) string. Также для каждого запроса вам нужно проверить количество найденных кафе. Поиск делайте в городе Москве - city=moscow. Как минимум проверьте следующие варианты:

    search=фасоль — не возвращается ни одного кафе;
    search=кофе — возвращается два кафе;
    search=вилка — возвращается одно кафе.

В функции можно определить тестовую таблицу со структурами типа:

    requests := []struct {
        search    string   // передаваемое значение search 
        wantCount int      // ожидаемое количество кафе в ответе
    }{
        ...
    }

### Подсказки

    Проверяйте, что запросы выполняются успешно вызовом require.Equal(t, http.StatusOK, response.Code).
    Не забывайте удалять лишний перевод строки с помощью strings.TrimSpace(response.Body.String()).
